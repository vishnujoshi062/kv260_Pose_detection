# Results

Output from running the demo on the KV260 goes here: screenshots (`.png`) and short clips (`.mp4`).

Videos and archives are ignored by git by default (see `.gitignore`), except files in this folder. Keep clips small, or host them elsewhere and link them from here.

Add a screenshot named `demo.png` here and show it in this file with `![demo output](demo.png)`. Describe the run, for example:

