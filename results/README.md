# Results

Output from running the demo on the KV260 goes here: short clips (`.mp4`).

Videos and archives are ignored by git by default (see `.gitignore`), except files in this folder. Keep clips small, or host them elsewhere and link them from here.

## Example

```
./seg_and_pose_detect_x seg_960_540.avi 0 -t 3 -t 3
```
